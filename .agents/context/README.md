# Context

Reference material agents read to understand this project. These files are
not actions to run; they are background to consult while doing other work.

| Area | Folder |
|------|--------|
| Development specification (architecture, conventions, git workflow, prerequisites) | [`dev-spec/`](dev-spec/) |
| Content design, design language, and fact references | [`products/`](products/) |

> Contrast with [`../skills/`](../skills/), which define things the agent
> *does*; this folder is what the agent *reads*.
