# Agent Memory (shared)

Shared, **committed** agent memory. Notes placed here are version-controlled
and visible to everyone working on the repo. Good candidates: decisions about
the story ("we merged chat and system prompt and then split them again —
here's why"), tuned visual values worth keeping, and gotchas in the Pixel
Field.

For machine-local notes that should not be committed, use
[`../local/`](../local/) instead.
